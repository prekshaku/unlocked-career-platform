# 🚀 UnlockED – AI-Powered Career Guidance Platform

### From Career Confusion to Career Clarity.

UnlockED is an AI-powered career guidance platform designed to help students discover suitable career paths, identify skill gaps, access personalized learning resources, and explore relevant internship and job opportunities.

## 🎯 Problem Statement

Students often struggle to connect their education, skill development, and career opportunities because resources and guidance are scattered across different platforms.

UnlockED aims to bring these elements together in one personalized platform.

## 💡 Our Solution

UnlockED provides a guided career development experience through:

- 🎯 Career Interest Assessment
- 📊 Personalized Skill Gap Analysis
- 🤖 AI-Powered Career Recommendations
- 📚 Recommended Learning Resources
- 🗺️ Personalized Career Roadmaps
- 📈 Learning Progress Tracking
- 💼 Internship and Job Opportunities

## ⚙️ Technology Stack

| Component | Technology |
|---|---|
| Frontend | React |
| Backend | FastAPI |
| Database | PostgreSQL |
| AI Integration | Gemini API |
| Frontend Deployment | Vercel |
| Backend Deployment | Render |

## 🔄 How It Works

1. Student creates a profile.
2. Completes a career interest assessment.
3. Platform identifies skill gaps.
4. AI generates personalized recommendations.
5. Student receives a learning roadmap.
6. Student tracks progress.
7. Student explores relevant opportunities.
